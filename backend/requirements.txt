# Note: we use plain `uvicorn` + `websockets` instead of `uvicorn[standard]`
# because httptools/watchfiles lack prebuilt wheels for 32-bit Python on
# Windows. On 64-bit Python / the Raspberry Pi you may use uvicorn[standard].
# If `cryptography` fails to build (32-bit Windows w/o Rust), the app still
# runs - API keys are simply stored unencrypted until you install it.
